## 3. Architecture Gates

### 3.1 Tenant isolation — PASS

All freight-cost repository reads/writes scoped by `tenant_id`:

- `CostSummaryProjectionRepository.GetByTransportOrder(Tx)`: `WHERE tenant_id = $1 AND transport_order_id = $2`
- Mapping load: `tenant_id = $1` for TENANT scope
- Cross-tenant read returns 404 (masked): `TestFC_B_SEC_004`, `TestFC_C_SEC_006`
- Cross-tenant mapping denied at handler: `variance_handler.go` L113–115

### 3.2 Trusted identity only — PASS

- Production handlers use gateway-injected headers (`X-Tenant-ID`, `X-User-ID`, `X-Company-ID`, `X-Actor-Kind`) parsed in `security/actor.go`
- No production trust of `X-Platform-Admin`, `X-Freight-Cost-Platform-Admin`, or unsigned role escalation
- Internal rebuild/reconcile/reclassify require `internalauth` token (`TestFC_C_SEC_007`, `TestFC_B_SEC_001`)

### 3.3 Historical pinned mapping (F48001) — PASS

`LoadPinnedMappings` uses:

```sql
effective_from <= pinnedEvaluationTime
AND (effective_to IS NULL OR effective_to > pinnedEvaluationTime)
AND mapping_version <= pinnedVersion
```

Evidence: `charge_code_mapping_repository.go`, tests `MAP-PIN-001/002`, `MAP-PIN-TIME-005`, `TestBonus_MAP_PIN_002_PinnedLoadExcludesHigherMappingVersion`.

`HISTORICAL_REPLAY_STABLE=YES`  
`CURRENT_MAPPING_CHANGES_DO_NOT_REWRITE_HISTORY=YES`

### 3.4 Platform admin auth (F48002) — PASS

- Platform mapping mutation **disabled** at repository and handler layers
- `TestBonus_SEC_ADMIN_001/002`: 403 even with spoofed platform-admin header
- `TestParseTrustedActorRejectsPlatformAdmin`: rejects `X-Actor-Kind: PLATFORM_ADMIN`

### 3.5 Canonical reclassification (F48003) — PASS

- `ReclassifyAttribution` accepts no client billing/transport facts; hydrates via `buildCanonicalDriverContext`
- HTTP handler ignores request body (intent-only)
- Tests: `TestBonus_SEC_RECLASS_001/002`, `TestFC_C_RBL_008`
- Financial amounts invariant enforced: `ErrReclassificationChangedFinancialAmounts`

### 3.6 Canonical reconciliation (F48004) — PASS

- `ReconcileTransportOrder` reads canonical facts, writes findings only
- Guard: `ErrReconciliationMutatedProjection` if projection revision changes
- Response explicitly: `auto_rebuild: false`, `auto_repair: false`
- Tests: `TestFC_C_REC_010`, `TestBonus_REC_CANON_003`

### 3.7 Money precision — PASS

- Go: `shopspring/decimal` throughout domain/services
- DB: `NUMERIC(18,2)` for amounts; `CHAR(3)` currency
- No authoritative float64 money logic (only test comment referencing float mishandling in `ledger_mon_integration_test.go`)
- Currency drift detected in reconciliation (`FindingCurrencyDrift`)

### 3.8 Audit immutability — PASS

- `cost_entry`: append-only via DB triggers (`deny_cost_entry_mutation`)
- Reclassification: supersede + insert attribution rows, no silent amount overwrite
- Projection upsert is derived-state materialization (not source-fact mutation)

### 3.9 Transaction boundaries — PASS

- Reconcile/reclassify/recompute use explicit `pgx.Tx` with commit/rollback
- Reconciliation fails closed if projection mutated mid-transaction

### 3.10 Idempotency — PASS

- Source events: unique `(tenant_id, source_event_id)` and `(tenant_id, source_fact_id)`
- Reconciliation findings: upsert by stable identity; idempotent re-run tests in `reconciliation_integration_test.go`
