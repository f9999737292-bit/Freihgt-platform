# Freight Cost Workspace v2.1E — Live Integration

## Architecture

```text
web-procurement (JWT + X-Company-ID)
       ↓
API Gateway (/api/v1/freight-costs/*)
       ↓ trusted identity + S2S token
freight-cost-service (/internal/v1/freight-costs/*)
       ↓
cost_summary_projection + canonical domain
```

Browser never calls internal service URLs or S2S tokens.

## Public API

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/api/v1/freight-costs` | Paginated workspace list |
| GET | `/api/v1/freight-costs/summary` | Aggregate KPIs |
| GET | `/api/v1/freight-costs/transport-orders/{id}` | Order detail |
| GET | `/api/v1/freight-costs/transport-orders/{id}/variance-detail` | Variance drivers |
| GET | `/api/v1/freight-costs/accessorials/summary` | Accessorial rollup (empty until enriched) |
| GET | `/api/v1/freight-costs/carriers/performance` | Carrier rollup |
| GET | `/api/v1/freight-costs/lanes/performance` | Lane rollup (empty until lane data) |

## Security

- JWT required at gateway (`freightcostrbac`)
- Company membership verified; spoofed tenant/role headers stripped
- Carrier responses mask buyer-internal fields server-side (`ApplyViewScope`)
- Feature flag remains `NUXT_PUBLIC_FREIGHT_COST_WORKSPACE_ENABLED` default OFF

## Rollout

Enable workspace per environment after CI green and human review. Do not auto-enable in production.

## Known limitations

- Lane performance and accessorial summary return empty items until dedicated projections exist
- Order reference / carrier name use transport-order / company IDs as fallback labels
