# Freight Cost Workspace v2.1E — Live Integration

## Architecture

```text
web-procurement (JWT + X-Company-ID)
       ↓
API Gateway (/api/v1/freight-costs/*)
       ↓ trusted identity + S2S token
freight-cost-service (/internal/v1/freight-costs/*)
       ↓
cost_summary_projection + canonical domain
```

Browser never calls internal service URLs or S2S tokens.

## Public API

| Method | Path | RBAC | Purpose |
|--------|------|------|---------|
| GET | `/api/v1/freight-costs` | PolicyRead | Paginated workspace list (limit max 100) |
| GET | `/api/v1/freight-costs/summary` | PolicyRead | Aggregate KPIs |
| GET | `/api/v1/freight-costs/transport-orders/{id}` | PolicyRead | Order detail |
| GET | `/api/v1/freight-costs/transport-orders/{id}/variance-detail` | PolicyBuyerAnalytics | Variance drivers |
| GET | `/api/v1/freight-costs/accessorials/summary` | PolicyBuyerAnalytics | Accessorial rollup |
| GET | `/api/v1/freight-costs/carriers/performance` | PolicyRead | Carrier rollup |
| GET | `/api/v1/freight-costs/lanes/performance` | PolicyRead | Lane rollup |

OpenAPI: `packages/openapi/freight-cost-service.yaml` (mirrored in unified `openapi.yaml`). Parity gate: `FREIGHT_COST_PUBLIC_ROUTE_PARITY=PASS` via `scripts/openapi/test_path_structure.py`.

## Security

- JWT required at gateway (`freightcostrbac`)
- Company membership verified; spoofed tenant/role/platform-admin headers stripped
- Carrier responses mask buyer-internal fields server-side (`ApplyViewScope`, JSON `omitempty`)
- Feature flag remains `NUXT_PUBLIC_FREIGHT_COST_WORKSPACE_ENABLED` default OFF

## Rollout

Enable workspace per environment after CI green and human review. Do not auto-enable in production.

## Limitations

- Lane/accessorial analytics projections not yet implemented; API returns `data_capability: NOT_AVAILABLE`
- Order reference / carrier name enrichment pending; UUIDs are not shown under human labels (empty + i18n unavailable)
- Reclassification/reconciliation public commands not in v2.1E read-only workspace scope (E2E-006/007 N/A for this PR)
