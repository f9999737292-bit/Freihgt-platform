## Что уже известно без ответа провайдера

Первый запрос — Microsoft. У Azure Confidential Ledger есть preview `waitForCommit=true`: ответ после commit и receipt. Это не гарантия производства. Точного successor нет в документации. Повтор после обрыва может создать вторую запись. Владелец подписки может удалить ledger. Цена на публичной странице не прочитана числом.

AWS: DynamoDB даёт условие на ключ и штатный PITR. S3 compliance mode не даёт root удалить версию на месте, но delete marker меняет текущее имя, а закрытие аккаунта — документированный ранний путь. Составная атомарность двух сервисов не описана. Цифра $0.75 за миллион — это один write и одно сильное чтение по примеру тарифа, не полный бюджет anchor.

Google: блокировка retention необратима и не равна lien. Lien снимает владелец проекта или администратор организации, после чего запрет удаления проекта с этого lien снят. Снятие lien не снимает retention с bucket. Защита от компрометации этого аккаунта не доказана.

Rekor: публичный журнал обнаруживает развилку у свидетеля, который хранит старый checkpoint. Он не отклоняет чужой sequence. Адрес `security@sigstore.dev` предназначен для уязвимостей. Для этого запроса получатель не подтверждён.

Получатель ни одного из четырёх запросов не подтверждён как канал квалификации. Опубликованный ящик команды Azure на странице коннектора не считается разрешением его использовать.

## Чеклист

| 1 | Ответ провайдера, а не пересказ рекламной страницы, по exact successor: атомарно `seq_new = seq_current + 1` с namespace, incarnation и predecessor digest | `NO` |
| 2 | Успешный ACK означает сохранность записи после аварии узла и восстановления | `NO` |

| 5 | Администратор anchor не является администратором трёх существующих серверов | `NO` |

## English gate, same rule

A pilot starts only after a named provider's written answers cover items 1–9 and the controller accepts them. A quotation that omits the successor rule, the lost-response rule, or the account-owner delete path does not open the pilot.
