# Provider contact verification sources 0.1X

Checked 2026-11-18. Each row is a public page read for this qualification. A row records what the page says about the channel. It does not record a provider answer, because no request was sent.

## Microsoft

| Source | What it establishes |
| --- | --- |
| https://learn.microsoft.com/en-us/azure/azure-portal/supportability/how-to-create-azure-support-request | A support request is opened in the Azure portal, by REST, or by Azure CLI. Technical support requires a support plan. The caller needs a subscription role. The case collects the issue type, the service, problem details, the support plan, a contact method, and contact details. |
| https://azure.microsoft.com/en-us/support/legal/faq | One-to-one technical support requires a paid support plan. Billing and subscription support is included. Public-preview technical support is limited to break-fix. Advisory support is general how-to. Professional Direct advisory support does not include verification of specifications or detailed architectural guidance. |
| https://azure.microsoft.com/en-us/support/plans | Basic does not include technical support. Developer is listed at $29 per month. Standard is listed at $100 per month. Developer and Standard architecture support is general guidance. |
| https://azure.microsoft.com/en-us/support/ | Billing and subscription support is available to Azure customers. Technical support is available to customers with a support plan. |
| https://azure.microsoft.com/en-us/contact | Azure publishes a regional sales contact directory. The page is a sales channel. |
| https://learn.microsoft.com/en-us/connectors/acl/ | The connector page publishes a team mailbox. It does not assign that mailbox to durability, deletion, or price questions. The mailbox stays excluded. |

## AWS

| Source | What it establishes |
| --- | --- |
| https://aws.amazon.com/contact-us/ | Technical support is unavailable under the Basic Support Plan. Account and billing support is separate. Compliance support is a separate request. |
| https://docs.aws.amazon.com/awssupport/latest/user/case-management.html | A Basic Support customer cannot create a technical support case. Account, billing, and service-quota cases are available to all customers. Low severity covers a general development question or a feature request. |
| https://docs.aws.amazon.com/awssupport/latest/user/aws-support-plans.html | Basic includes account and billing help, forums, service health, and documentation. Business Support+ adds access to Cloud Support Engineers. Developer Support is announced to end on 2027-01-01. |
| https://aws.amazon.com/premiumsupport/pricing/ | Business Support+ is listed at a minimum of $29 per month per account. Enterprise Support is listed at a minimum of $5,000 per month. |
| https://aws.amazon.com/contact-us/sales-support-pricing/ | Pricing specialists take a web form for questions and a pricing quote, with a stated reply within one business day. The same page sends technical issues to a signed-in support request. |

## Google Cloud

| Source | What it establishes |
| --- | --- |
| https://docs.cloud.google.com/support/docs/customer-care-procedures | A case is created in the console for an organization or a project. The form asks for product, description, error, priority, category, and chat or email. A support package opens the technical case path. Basic includes billing questions. |
| https://docs.cloud.google.com/support/docs/downgrade | Users with Basic support cannot create technical support cases. |
| https://cloud.google.com/support | Basic is included for every Google Cloud customer, including a free trial. |
| https://cloud.google.com/support/standard | Standard Support lists a minimum of $29.00 or 3 percent of monthly Cloud charges, whichever is higher. |
| https://cloud.google.com/contact/form | A sales form collects business identity and a problem description of up to 1000 characters. It points technical support to the Cloud Support Hub. |
| https://cloud.google.com/support-hub | No mailbox for this qualification is published on the support hub. |

## What these sources do not establish

No page above names a recipient who is authorized to answer Q1–Q10 in writing without a paid technical-support relationship, and no paid-support page says that the relationship includes those written guarantees. Prices of support plans are the prices printed on the cited pages. They are not a quote for the anchor and they are not an offer accepted by BINTRANS.
