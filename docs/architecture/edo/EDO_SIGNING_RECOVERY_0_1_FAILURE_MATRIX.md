# EDO signing recovery 0.1 — failure matrix

Facts below are what the code on `3f306fc407aeda4bdc652d825954292f4a54fad6` does today. The recovery column is the proposed rule for stage 0.2 and later. It is not implemented by this document.

`RESULT_UNKNOWN` is a proposed state. The current schema has no such session status. A missing response must not be stored as `FAILED`.

## Proposed rule for every unknown external result

If the process cannot prove that the provider did not accept the operation, the local state becomes `RESULT_UNKNOWN`. That state is not `FAILED`. A new provider call waits for reconciliation or for a written idempotency guarantee of that provider interface. The current code has no provider, so this rule is a design constraint for 0.4, not a behavior of 0.1.
