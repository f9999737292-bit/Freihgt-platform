# Создать тендер из Excel

Руководство для покупателя. Оно объясняет, как из книги Excel получить новый черновик тендера. Текст самодостаточен: рисунки для прохождения не нужны. В этом выпуске рисунков нет.

Предмет называется **тендер**. На экране список называется «Тендеры».

## Кому доступна кнопка

Кнопка **«Создать из Excel»** видна в списке тендеров только тогда, когда функция включена и ваша роль позволяет создавать тендер. Если кнопки нет, она не спрятана в другом меню.

Слова вроде внутреннего имени набора ролей на экране нет. Ориентируйтесь на кнопку и на текст страницы.

## Где находится кнопка

1. Откройте список **«Тендеры»**.
2. Нажмите **«Создать из Excel»**.
3. Откроется страница **«Создать тендер из Excel»**.

Под заголовком уже сказано: загрузите книгу, проверьте замечания и создайте новый черновик. Публикация и добавление участников на этой странице не выполняются.

## Если функция недоступна

Страница может открыться и без кнопки в списке. Тогда вместо формы видна фраза **«Создание из Excel недоступно для этой роли или флага.»** Это не поломка учётной записи. Функция выключена либо этой роли создание из Excel не разрешено.

Кнопка **«Скачать пустой шаблон»** в этом состоянии не показывается. Не пытайтесь создать тендер повторными нажатиями.

## Вернуться к ручному созданию

На странице есть **«К ручному созданию»**. Она открывает обычный мастер **«Создать тендер»**. Это другой путь: мастер ведёт через общие данные, лоты, участников и публикацию. Страница Excel этого не делает.

Если Excel недоступен, ручное создание остаётся отдельным способом начать тендер. Книга Excel не обходит недоступную функцию.

## Скачать пустой шаблон

На рабочей странице нажмите **«Скачать пустой шаблон»**. Пока файл скачивается, видно **«Скачиваем пустой шаблон»**. После успеха видно **«Пустой шаблон скачан. Заполните его и загрузите на этой странице. Скачивание не создаёт тендер.»**

Файл называется `bintrans-rfx-buyer-xlsx-v1-create-template.xlsx`. Подсказка под кнопкой говорит то же самое: шаблон нужен для нового тендера через «Создать из Excel», загрузка и создание не публикуют тендер и не добавляют участников.

## Скачивание не создаёт тендер

После скачивания в списке «Тендеры» ничего нового не появляется. Тендер появится только после успешного **«Создать тендер»** и перехода в карточку.

## Семь листов

В пустой книге семь листов, в таком порядке:

| Лист | Что это для покупателя |
| --- | --- |
| Instructions | Пояснение, как создать новый черновик. Публикации и добавления участников там нет. |
| Metadata | Служебные строки книги. Их нельзя очищать. |
| Lots | Лоты. В пустой книге только заголовки. |
| Sections | Разделы. В пустой книге только заголовки. |
| Questions | Вопросы. В пустой книге только заголовки. |
| Options | Варианты ответов. В пустой книге только заголовки. |
| Rules | Правила. В пустой книге только заголовки. |

Пустые лоты, разделы и вопросы для нового черновика допустимы.

## Metadata

На листе Metadata уже есть строки `schema_name` и `schema_version`. Не удаляйте их и не заменяйте другими словами. Без этих строк книга перестаёт быть пустым шаблоном этой страницы.

Не вставляйте в книгу формулы и не копируйте в руководство содержимое ячеек целиком.

## Листы только с заголовками

Только Lots, Sections, Questions, Options и Rules начинаются с одной строки заголовков. Metadata к ним не относится: там уже лежат две служебные строки.

Если лоты, разделы и вопросы не нужны, оставьте эти пять листов пустыми под заголовками. Не удаляйте сами листы и не переименовывайте их.

## Обязательные поля на странице

Блок называется служебным именем «Метаданные тендера»; на форме видны обычные подписи:

| Подпись | Что сделать |
| --- | --- |
| Компания-заказчик | Оставить свою компанию. В учебном примере имя на экране — Demo Buyer. Не копируйте служебный идентификатор компании. |
| Номер | Можно заменить предложенный номер. В учебном примере: `RFX-DEMO-001`. Это номер тендера. |
| Название | Введите название. В учебном примере: «Демонстрационный тендер из Excel». Пока поле пустое, предпросмотр его потребует. |
| Тип | По умолчанию код `SPOT_RFQ`. Это разовый запрос. Код на экране не переименовывайте. |
| Категория | По умолчанию код `FREIGHT`. Это перевозка. Код на экране не переименовывайте. |

Пока обязательное поле пустое, страница пишет **«Перед предпросмотром заполните обязательные поля тендера.»** и запрос не отправляет.

## Дополнительные поля

Их можно оставить пустыми:

- Описание
- Дедлайн ответа
- Валюта

Пустое дополнительное поле не мешает предпросмотру. Заполняйте их только если они нужны этому тендеру.

## Только .xlsx и 5 МиБ

Подходит только файл с расширением `.xlsx`. Другое расширение даёт фразу **«Допускаются только файлы .xlsx.»**

Максимальный размер — 5 МиБ. На странице это написано как **«Максимальный размер файла 5 МиБ»**. Если файл больше, видно **«Файл больше 5 МиБ.»** Уменьшите книгу. Тот же файл повторно не отправляйте.

Подпись выбора файла — **«Книга XLSX»**, кнопка — **«Выберите файл XLSX»**. Если файл не выбран, видно **«Перед предпросмотром выберите файл XLSX.»**

## Загрузка и предпросмотр

1. Заполните обязательные поля.
2. Выберите заполненную или пустую совместимую книгу `.xlsx`.
3. Нажмите **«Предпросмотр»**.

Пока проверка идёт, статус такой: **«Идёт предпросмотр. Тендер ещё не создан.»**

## Предпросмотр не создаёт тендер

После предпросмотра тендер в списке не появляется. Предпросмотр только показывает, можно ли создавать черновик.

Когда можно создавать, статус такой: **«Предпросмотр готов. Можно создать тендер.»** Строка **«Готово к созданию»** показывает **«Да»**. Кнопка **«Создать тендер»** становится доступна.

В блоке результата есть **«Предложение»** с названием и номером, а также счётчики **«Лоты»**, **«Разделы»**, **«Вопросы»**, **«Ошибки»** и **«Предупреждения»**.

Строка **«Идентификатор предпросмотра»** может показать длинное служебное значение. Не копируйте его в письмо, заявку или учебный материал. Строка **«Режим создания»** на этой странице означает, что готовится новый черновик, а не правка уже открытого тендера.

## Предупреждение и блокирующая ошибка

Замечания собраны под заголовком **«Замечания»**.

- Блокирующая ошибка увеличивает **«Ошибки»**. Статус: **«Предпросмотр нашёл проблемы. Создание отключено.»** **«Готово к созданию»** показывает **«Нет»**. Кнопка **«Создать тендер»** недоступна. Исправьте книгу и снова нажмите **«Предпросмотр»**.
- Предупреждение увеличивает **«Предупреждения»**. Оно может быть и тогда, когда **«Готово к созданию»** уже **«Да»**. Предупреждение само по себе не запрещает создание. Читайте текст замечания, а не цвет строки.

Если книга читается, но черновик из неё создать нельзя, фраза такая: **«Файл читается, но тендер создать нельзя.»**

## Строку «Код:» не копировать

У ошибки под обычной фразой может появиться строка, которая начинается с **«Код:»**. Читайте и пересказывайте фразу над ней. Саму строку **«Код:»** не копируйте в обращение, в учебный текст и в переписку с поставщиком. Для поддержки достаточно текста замечания, номера тендера и того, какое действие вы делали: скачивание, предпросмотр или создание.

## Смена файла или полей сбрасывает предпросмотр

Если после готового предпросмотра вы меняете файл или любое поле из обязательных и дополнительных, страница сбрасывает результат. Статус: **«Предпросмотр сброшен. Запустите его снова.»** Кнопка **«Создать тендер»** снова недоступна.

Новый предпросмотр обязателен. Старым результатом пользоваться нельзя: он уже не соответствует экрану.

## Защита от двойного нажатия

Нажмите **«Создать тендер»** один раз. Пока идёт создание, статус **«Создаём черновик тендера»**, и кнопка не нажимается. После успеха она остаётся недоступной. Второй щелчок в этот момент ничего не отправляет.

Успех на странице: **«Черновик тендера создан из Excel»** и статус **«Черновик тендера создан»**. Затем открывается карточка этого тендера.

## Результат остаётся черновиком

В карточке подпись **«Статус»** показывает код `DRAFT`. Этот код значит черновик. Тендер не становится опубликованным из-за создания из Excel.

## Канал создания

В той же карточке подпись **«Канал создания»** показывает **«Создан из Excel»**. Так видно, что черновик появился с этой страницы, а не из ручного мастера.

## Публикации нет

Страница не публикует тендер. Не нажимайте **«Опубликовать»** в рамках этого сценария. Пока статус `DRAFT`, тендер остаётся черновиком, даже если кнопка публикации на карточке видна.

## Участники не добавляются

Создание из Excel не приглашает перевозчиков и не добавляет участников. В карточке ожидается состояние **«Участники не добавлены»**. Это нормальный результат, а не ошибка.

## ERP не вызывается

Эта страница не отправляет тендер во внешнюю учётную систему. Канал **«Создан из Excel»** не означает канал ERP. Ничего в ERP открывать и проверять не нужно.

## Если результат создания неясен

Так бывает при обрыве сети или при временной недоступности, когда фраза одна: **«Создание из Excel временно недоступно.»**

1. Откройте список **«Тендеры»** и найдите введённый номер, в примере `RFX-DEMO-001`.
2. Если карточка уже есть, статус `DRAFT` и канал **«Создан из Excel»**, второй тендер не создавайте.
3. Если номера в списке нет и на странице по-прежнему готовый предпросмотр, один раз можно снова нажать **«Создать тендер»**.
4. Если предпросмотр не сохранился на экране, снова нажмите **«Предпросмотр»**, а не создание.

Если видно **«Этот запрос на создание конфликтует с другим запросом.»**, не нажимайте **«Создать тендер»** пачкой. Сначала проверьте список. Если черновика нет, запустите предпросмотр заново.

## Создание нового тендера и правка существующего черновика

Это разные страницы.

| | Новый тендер из Excel | Правка существующего черновика |
| --- | --- | --- |
| Откуда открыть | Список «Тендеры», кнопка «Создать из Excel» | Карточка уже существующего тендера |
| Заголовок | Создать тендер из Excel | Обновить черновик из Excel |
| Главное действие | Создать тендер | Применить к черновику |
| Результат | Новый черновик, канал «Создан из Excel» | Меняется тот черновик, который уже открыт |

Пустой шаблон со страницы «Создать тендер из Excel» не обновляет уже существующий тендер. Книга, выгруженная из карточки для правки, не заменяет этот пустой шаблон.

Ручной мастер «Создать тендер» — третий путь. Он не является ни этой загрузкой Excel, ни правкой черновика из карточки.
